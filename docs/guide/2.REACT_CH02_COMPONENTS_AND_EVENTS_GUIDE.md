## 1. Chapter 02 핵심 개념 정리 (Spring/Servlet 개발자 관점)

### 💡 1) 컴포넌트와 Props (Component & Props)
- **클래스 컴포넌트 (`React.Component`)**: 과거 자바의 객체지향 상속 방식과 흡사합니다. `extends Component<P, S>` 형태로 작성하며 `render()` 메서드에서 JSX를 반환합니다. `this.props`로 데이터를 읽습니다.
- **함수형 컴포넌트 (`React.FC`)**: 최신 리액트 표준입니다. 단순히 매개변수(`props`)를 받아 JSX를 반환하는 순수 함수 형태이므로 보일러플레이트 코드가 적고 훨씬 직관적입니다.
- **Props (속성)**: 부모 컴포넌트가 자식 컴포넌트에게 전달하는 **읽기 전용(Read-Only) 데이터**입니다. Spring MVC에서 컨트롤러가 Model에 데이터를 담아 JSP로 넘겨주면, JSP에서 `${data}`로 읽기만 하듯이 자식 컴포넌트는 전달받은 props를 직접 수정할 수 없습니다.

### 💡 2) `key`와 `children` 속성
- **`key` 속성**: 배열 데이터를 `map()`으로 돌려 반복 렌더링할 때 리액트 가상 DOM 엔진이 각 항목을 식별하기 위한 '고유 주민번호'입니다. **실제 브라우저 물리 DOM(HTML 태그)에는 렌더링되지 않고 증발**합니다.
- **`children` 속성**: `<Tag>내용</Tag>`처럼 태그와 태그 사이에 끼워 넣은 자식 요소들을 컴포넌트 내부에서 받아올 때 사용하는 특별한 예약어 props입니다. TypeScript에서는 `PropsWithChildren<P>` 타입을 사용해 우아하게 정의합니다.

### 💡 3) 리액트 이벤트 시스템 (SyntheticEvent)
- **물리 DOM 이벤트(`onclick`) vs 리액트 합성 이벤트(`onClick`)**:
  - HTML 순수 자바스크립트는 소문자(`onclick`), 리액트는 카멜 케이스(`onClick`)를 사용합니다.
  - HTML `onclick`에 함수를 두 번 대입하면 뒤의 것이 앞의 것을 덮어써 버리지만, 리액트는 W3C 표준 규격에 맞춘 **합성 이벤트(`SyntheticEvent`)** 객체로 브라우저 간 차이를 통일하여 안전하게 처리합니다.
- **이벤트 버블링(Bubbling)과 전파 중단(`e.stopPropagation()`)**:
  - 버튼을 클릭하면 버튼(`target`)에서 시작해 부모 `div`, 상위 컨테이너로 이벤트가 타고 올라갑니다.
  - `e.stopPropagation()`을 호출하면 부모 요소로 이벤트가 전파되는 것을 즉시 차단합니다.
- **폼 입력 제어 & 파일 드래그앤드롭**:
  - `<input type="text">`, `checkbox`, `radio`의 값 변화는 `onChange` 이벤트와 `e.target.value`, `e.target.checked`로 감지합니다.
  - 파일 업로드는 `e.target.files` (`FileList` 객체)를 통해 처리하며, 드래그 앤 드롭은 브라우저의 기본 동작(파일 새 창 열기)을 막기 위해 `e.preventDefault()`를 호출한 뒤 `e.dataTransfer.files`를 읽습니다.

## Step 1: Chapter 02_03 컴포넌트 & Props 실습 컴포넌트 작성

### 1-1. 클래스 컴포넌트 (`src/practices/ch02_components/ClassComponent.tsx`)
- **역할**: `Component` 상속과 `render()` 메서드를 통해 `href`와 `text` props를 전달받아 링크 목록 항목(`<li>`)을 렌더링합니다.
- **상태**: `[신규 생성]`

```tsx
import { Component } from 'react';

/**
 * 클래스 컴포넌트가 전달받을 Props 타입 정의
 */
export type ClassComponentProps = {
  href: string;
  text: string;
};

/**
 * 클래스 컴포넌트: 반드시 Component 클래스를 상속받고 render() 메서드를 구현해야 함
 */
export default class ClassComponent extends Component<ClassComponentProps> {
  render() {
    // this.props를 통해 부모가 전달한 속성값을 구조 분해 할당
    const { href, text } = this.props;
    return (
      <li style={{ marginBottom: '8px' }}>
        <a
          href={href}
          target="_blank"
          rel="noopener noreferrer"
          style={{ color: '#2563eb', textDecoration: 'none', fontWeight: 600 }}
        >
          🏛️ [ClassComponent] {text}
        </a>
      </li>
    );
  }
}
```

### 1-2. 화살표 함수 컴포넌트 (`src/practices/ch02_components/ArrowComponent.tsx`)
- **역할**: 함수형 컴포넌트의 표준인 `FC` 타입을 적용하여 동일한 링크 목록 항목(`<li>`)을 간결하게 구현합니다.
- **상태**: `[신규 생성]`

```tsx
import type { FC } from 'react';

/**
 * 화살표 함수 컴포넌트가 전달받을 Props 타입 정의
 */
export type ArrowComponentProps = {
  href: string;
  text: string;
};

/**
 * 화살표 함수 컴포넌트: React.FC 제네릭 타입을 통해 props 규격을 보장
 */
const ArrowComponent: FC<ArrowComponentProps> = props => {
  const { href, text } = props;
  return (
    <li style={{ marginBottom: '8px' }}>
      <a
        href={href}
        target="_blank"
        rel="noopener noreferrer"
        style={{ color: '#10b981', textDecoration: 'none', fontWeight: 600 }}
      >
        🏹 [ArrowComponent] {text}
      </a>
    </li>
  );
};

export default ArrowComponent;
```

## Step 2: Chapter 02_04 key & children 속성 실습 작성

### 2-1. PropsWithChildren을 활용한 태그 래퍼 (`src/practices/ch02_components/P.tsx`)
- **역할**: 자식 요소(`children`)를 받아 `<p>` 태그로 감싸 출력해 주는 래퍼 컴포넌트입니다.
- **상태**: `[신규 생성]`

```tsx
import type { FC, PropsWithChildren } from 'react';

export type PProps = {
  color?: string;
};

/**
 * PropsWithChildren: 컴포넌트에 기본적으로 children?: ReactNode 속성을 주입해 주는 유틸 타입
 */
const P: FC<PropsWithChildren<PProps>> = props => {
  const { color = '#374151', children, ...rest } = props;
  return (
    <p style={{ color, margin: '6px 0', fontSize: '14px' }} {...rest}>
      {children}
    </p>
  );
};

export default P;
```

- **상태**: `[신규 생성]`

```tsx
import React, { useState } from 'react';
import type { SyntheticEvent, ChangeEvent, DragEvent } from 'react';

/**
 * Chapter 02-05: 리액트 이벤트 시스템 및 폼/파일 입력 종합 실습
 */
export const EventPractice: React.FC = () => {
  // 폼 입력 상태값 관리
  const [textInput, setTextInput] = useState('');
  const [isChecked, setIsChecked] = useState(true);
  const [selectedRadio, setSelectedRadio] = useState('react');
  const [rangeVal, setRangeVal] = useState(50);
  const [fileLogs, setFileLogs] = useState<string[]>([]);
  const [eventLogs, setEventLogs] = useState<string[]>([]);

  // 콘솔 및 화면에 로그를 함께 누적하는 헬퍼 함수
  const addLog = (message: string) => {
    console.log(`[EventLog] ${message}`);
    setEventLogs(prev => [message, ...prev.slice(0, 7)]); // 최근 8개 로그 유지
  };

  // 1. 버블링 테스트 핸들러
  const handleParentClick = (e: SyntheticEvent) => {
    addLog(`부모 <div> 클릭 감지! (bubbles: ${e.bubbles})`);
  };

  const handleChildNormalClick = (e: SyntheticEvent) => {
    addLog(`자식 버튼(일반) 클릭 -> 부모로 버블링 발생!`);
  };

  const handleChildStopClick = (e: SyntheticEvent) => {
    e.stopPropagation(); // 👈 [핵심] 상위 부모로의 버블링 전파 차단!
    addLog(`자식 버튼(중단) 클릭 -> e.stopPropagation()으로 전파 차단됨!`);
  };

  // 2. 파일 입력 핸들러
  const handleFileChange = (e: ChangeEvent<HTMLInputElement>) => {
    const files = e.target.files;
    if (files) {
      const logs: string[] = [];
      for (let i = 0; i < files.length; i++) {
        const f = files.item(i);
        if (f) {
          logs.push(`선택 파일: ${f.name} (${Math.round(f.size / 1024)} KB)`);
        }
      }
      setFileLogs(logs);
      addLog(`파일 ${files.length}개 업로드 감지`);
    }
  };

  // 3. 파일 드래그 앤 드롭 핸들러
  const handleDragOver = (e: DragEvent<HTMLDivElement>) => {
    e.preventDefault(); // 기본 파일 열기 동작 방지
  };

  const handleDrop = (e: DragEvent<HTMLDivElement>) => {
    e.preventDefault(); // 새 탭 브라우저 열기 방지
    const files = e.dataTransfer.files;
    if (files && files.length > 0) {
      const logs: string[] = [];
      for (let i = 0; i < files.length; i++) {
        const f = files[i];
        logs.push(`드롭 파일: ${f.name} (${Math.round(f.size / 1024)} KB)`);
      }
      setFileLogs(logs);
      addLog(`드롭 영역에 ${files.length}개 파일 수신!`);
    }
  };

  return (
    <div className="practice-card">
      <div className="card-header">
        <span className="badge">Ch 02-05</span>
        <h3>⚡ 리액트 합성 이벤트 & 폼/파일 제어</h3>
      </div>
      <p className="description">
        리액트의 합성 이벤트(<code>SyntheticEvent</code>), 이벤트 버블링과 <code>stopPropagation()</code>, 그리고 다양한 Form & File 입력 제어 방식을 실시간으로 확인합니다.
      </p>

      <hr className="divider" />

      {/* 1. 이벤트 버블링과 stopPropagation */}
      <div className="practice-section">
        <h4>1. 이벤트 버블링(Event Bubbling) vs 전파 중단(stopPropagation)</h4>
        <div
          onClick={handleParentClick}
          style={{
            padding: '16px',
            backgroundColor: '#fef3c7',
            border: '2px dashed #f59e0b',
            borderRadius: '8px',
            cursor: 'pointer',
          }}
        >
          <p style={{ margin: 0, fontWeight: 700, color: '#b45309' }}>
            부모 영역 <code>&lt;div&gt;</code> (여기를 누르면 부모 클릭 로그 발생)
          </p>
          <div style={{ display: 'flex', gap: '10px', marginTop: '10px' }}>
            <button
              className="btn-primary"
              style={{ backgroundColor: '#f97316' }}
              onClick={handleChildNormalClick}
            >
              버블링 허용 버튼 (부모도 반응함)
            </button>
            <button
              className="btn-primary"
              style={{ backgroundColor: '#ef4444' }}
              onClick={handleChildStopClick}
            >
              버블링 차단 버튼 (stopPropagation)
            </button>
          </div>
        </div>
      </div>

      <hr className="divider" />

      {/* 2. 다양한 폼 인풋 제어 */}
      <div className="practice-section">
        <h4>2. 다양한 폼 입력 요소 (Various Inputs)</h4>
        <div style={{ display: 'grid', gridTemplateColumns: '1fr 1fr', gap: '12px' }}>
          <div>
            <label style={{ fontSize: '13px', fontWeight: 600 }}>텍스트 입력 (OnChange):</label>
            <input
              type="text"
              className="practice-input"
              style={{ width: '100%', padding: '8px', border: '1px solid #d1d5db', borderRadius: '6px', marginTop: '4px' }}
              placeholder="텍스트를 입력해 보세요"
              value={textInput}
              onChange={e => {
                setTextInput(e.target.value);
                addLog(`텍스트 입력: ${e.target.value}`);
              }}
            />
          </div>

          <div>
            <label style={{ fontSize: '13px', fontWeight: 600 }}>범위 슬라이더 (Range: {rangeVal}):</label>
            <input
              type="range"
              min="0"
              max="100"
              value={rangeVal}
              onChange={e => setRangeVal(Number(e.target.value))}
              style={{ width: '100%', marginTop: '10px' }}
            />
          </div>

          <div style={{ display: 'flex', alignItems: 'center', gap: '8px' }}>
            <input
              type="checkbox"
              id="chk"
              checked={isChecked}
              onChange={e => {
                setIsChecked(e.target.checked);
                addLog(`체크박스 토글: ${e.target.checked}`);
              }}
            />
            <label htmlFor="chk" style={{ fontSize: '14px', cursor: 'pointer' }}>

            </label>
          </div>

          <div style={{ display: 'flex', alignItems: 'center', gap: '12px' }}>
            <label style={{ fontSize: '13px', fontWeight: 600 }}>라디오:</label>
            <label style={{ fontSize: '13px' }}>
              <input
                type="radio"
                name="tech"
                value="react"
                checked={selectedRadio === 'react'}
                onChange={e => setSelectedRadio(e.target.value)}
              /> React
            </label>
            <label style={{ fontSize: '13px' }}>
              <input
                type="radio"
                name="tech"
                value="vue"
                checked={selectedRadio === 'vue'}
                onChange={e => setSelectedRadio(e.target.value)}
              /> Vue
            </label>
          </div>
        </div>
      </div>

      <hr className="divider" />

      {/* 3. 파일 입력 & 드래그 앤 드롭 (FileDrop) */}
      <div className="practice-section">
        <h4>3. 파일 선택 & 드래그 앤 드롭 (FileDrop)</h4>
        <input
          type="file"
          multiple
          accept="image/*"
          onChange={handleFileChange}
          style={{ marginBottom: '12px', display: 'block' }}
        />

        <div
          onDragOver={handleDragOver}
          onDrop={handleDrop}
          style={{
            padding: '30px',
            border: '2px dashed #3b82f6',
            borderRadius: '10px',
            backgroundColor: '#eff6ff',
            textAlign: 'center',
            color: '#1d4ed8',
            cursor: 'pointer',
          }}
        >
          📁 여기에 이미지 파일을 끌어다 놓으세요 (Drop files here)
        </div>

        {fileLogs.length > 0 && (
          <ul style={{ marginTop: '10px', fontSize: '13px', color: '#1e40af', paddingLeft: '20px' }}>
            {fileLogs.map((log, idx) => (
              <li key={idx}>{log}</li>
```

## 자주 발생하는 오류 & 체크리스트 (FAQ)

### Q1. `UserProfile` 컴포넌트에서 `isActive` 타입 오류가 발생합니다.
> **원인**: boolean 타입을 JSX에 `{isActive}` 형태로 직접 출력하려고 하면 리액트는 화면에 아무것도 그리지 않습니다.  
> **해결**: 삼항 연산자를 활용하여 문자열로 치환해야 합니다:  
> `{isActive ? '● 활성' : '○ 비활성'}`

### Q2. 드래그 앤 드롭 시 브라우저가 파일 뷰어로 바뀌어 버립니다.
> **원인**: `onDragOver` 또는 `onDrop` 이벤트 핸들러에서 `e.preventDefault()`를 빠뜨렸기 때문입니다.  
> **해결**: 드래그 앤 드롭 관련 핸들러 최상단에 반드시 `e.preventDefault()`를 선언하세요.

### Q3. `registry.ts`에 등록했는데 상단 바에 버튼이 안 생깁니다.
> **원인**: `id` 값이 중복되었거나 브라우저 캐시 문제일 수 있습니다.  
> **해결**: `registry.ts`의 `id`가 기존 실습들과 겹치지 않는 고유값인지 확인하고 브라우저를 강력 새로고침(`Ctrl + Shift + R`)합니다.
